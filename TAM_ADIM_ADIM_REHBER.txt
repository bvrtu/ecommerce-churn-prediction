ADIM 1: PROJE DİZİNİNE GİDİN
───────────────────────────────────────────────────────────────
cd /Users/bartu/Desktop/ecommerce-churn-prediction


ADIM 2: VIRTUAL ENVIRONMENT'I AKTİF EDİN
───────────────────────────────────────────────────────────────
source venv/bin/activate

(Başarılı olursa terminal'de (venv) yazısı görünecek)


ADIM 3: DATASET'İN VARLIĞINI KONTROL EDİN
───────────────────────────────────────────────────────────────
ls -lh data/raw/train.csv

Eğer dosya yoksa:
- Kaggle'dan dataset indirin (WA_Fn-UseC_-Telco-Customer-Churn.csv)
- data/raw/ klasörüne kopyalayın ve train.csv olarak adlandırın


ADIM 4: DATASET'İ YÜKLEYİP KONTROL EDİN
───────────────────────────────────────────────────────────────
python3 -c "
import sys
sys.path.insert(0, '.')
from src.data_loader import load_kaggle_ecommerce_churn
from src.config import RAW_DATA_DIR

df = load_kaggle_ecommerce_churn(RAW_DATA_DIR)
print(f'✅ Dataset yüklendi: {df.shape}')
print(f'Churn rate: {df[\"churn\"].mean():.2%}')
"

Bu komut dataset'in doğru yüklendiğini kontrol eder.


ADIM 5: MODELİ EĞİTİN VE TEST EDİN
───────────────────────────────────────────────────────────────
python3 train_and_test.py

Bu komut:
- Dataset'i yükler
- Modeli eğitir (XGBoost)
- Test setinde değerlendirir
- Performans metriklerini gösterir
- Modeli models/final_pipeline.pkl olarak kaydeder

Beklenen süre: 1-3 dakika


ADIM 6: SONUÇLARI KONTROL EDİN
───────────────────────────────────────────────────────────────
Çıktıda şunları göreceksiniz:
- Accuracy, Precision, Recall, F1-Score, ROC-AUC
- Confusion Matrix
- Business Impact Analizi
- Model kayıt konumu

PROBLEM: "ModuleNotFoundError: No module named 'src'"
ÇÖZÜM: Proje root dizininde olduğunuzdan emin olun
- cd /Users/bartu/Desktop/ecommerce-churn-prediction

PROBLEM: "XGBoost Library could not be loaded"
ÇÖZÜM: OpenMP kurulumu gerekli
- brew install libomp
- pip uninstall xgboost && pip install xgboost

PROBLEM: "Dataset not found"
ÇÖZÜM: Dataset'i kontrol edin
- ls -lh data/raw/train.csv
- Eğer yoksa Kaggle'dan indirip kopyalayın

PROBLEM: "Churn column not found"
ÇÖZÜM: Dataset'te Churn kolonu olmalı
- Dataset'inizde "Churn" veya "churn" kolonu olduğundan emin olun
