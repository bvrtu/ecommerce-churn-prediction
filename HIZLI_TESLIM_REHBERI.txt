ADIM 4: STREAMLIT CLOUD'DA DEPLOY EDİN
───────────────────────────────────────────────────────────────
1. https://streamlit.io/cloud adresine gidin
2. GitHub ile giriş yapın
3. "New app" butonuna tıklayın
4. Repository: YOUR_USERNAME/ecommerce-churn-prediction seçin
5. Branch: main
6. Main file path: streamlit_app.py
7. "Deploy!" butonuna tıklayın
8. 2-3 dakika bekleyin
9. Deployment linkinizi alın
