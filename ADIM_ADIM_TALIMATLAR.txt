═══════════════════════════════════════════════════════════════
SORUN GİDERME
═══════════════════════════════════════════════════════════════

PROBLEM: "ModuleNotFoundError: No module named 'pandas'"
ÇÖZÜM: Virtual environment aktif değil veya bağımlılıklar yüklenmemiş
- source venv/bin/activate
- pip install -r requirements.txt

PROBLEM: "Dataset not found"
ÇÖZÜM: Dataset oluşturun
- python3 src/data_loader.py

PROBLEM: "Churn column not found"
ÇÖZÜM: Dataset'inizde churn kolonu olmalı veya data_loader.py'yi güncelleyin

PROBLEM: Model eğitimi çok uzun sürüyor
ÇÖZÜM: src/config.py'de XGBOOST_PARAMS['n_estimators'] değerini azaltın
